# MiniBKN UI 自动化与真实浏览器验收报告

> 日期：2026-08-17

## 自动化测试

前端 Vitest 从 2 项扩充到 8 项，覆盖：

- 六个工作区与无障碍导航；
- 没有评测时不伪造数字；
- API 地址和密钥保存，密钥输入不明文展示；
- 数据源登记和字段发现；
- 问答路线、证据和引用；
- 后端错误展示且不虚构回答；
- 最新评测加载与 READY 状态；
- 所有建模提案审核完成前禁止发布。

结果：8/8 通过，TypeScript 检查通过，Vite 生产构建通过。

## 真实浏览器链路

实际完成：CRM 数据源登记、14 条提案生成与审核、网络发布、增量构建、结构化问答、供应链风险模拟、动作门禁、评测读取和移动端检查。

关键可见结果：

- CRM 自动发现 2 张表；
- 发布网络包含 2 类对象与 1 类关系；
- 增量构建写入 7 个对象、4 条关系、10 个索引文档；
- 问答显示结构、实例、关系和源数据行引用；
- `MAT-001` 补货动作被判定为 `confirm`，执行状态停在 `pending_confirmation`；
- 评测页成功加载约 5.5 KB 汇总报告并显示 READY；
- 浏览器控制台无 error/warning；
- 390 × 844 视口没有横向溢出。

## 测试发现的 UI 问题与修复

1. 评测页原先加载约 2 MB 逐题报告，改为由汇总脚本生成轻量 `latest.json`；
2. 已审核提案仍显示操作按钮，现只对 `pending` 提案显示接受/拒绝；
3. 未处理完提案时仍可点击发布，现按钮会禁用，并增加前端回归测试。
