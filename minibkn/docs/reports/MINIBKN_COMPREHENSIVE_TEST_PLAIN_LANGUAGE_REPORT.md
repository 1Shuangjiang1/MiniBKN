# MiniBKN 全量测试通俗报告

## 一句话结论

这次不是只检查“程序能不能启动”，而是给 MiniBKN 做了一次从原料、理解、搜索、回答、动作安全、更新速度到网页操作的全面体检。当前演示主流程已经可以完整跑通，真实模型也接通了；但 LightRAG 和企业级细粒度权限仍未完成。

## 我准备了哪些“考试题”

为了避免系统只会供应链，我另外造了三家虚拟公司的业务数据：采购、财务和人事。里面一共有 4,440 条业务记录、4,600 条关系，还故意放入了组合编号、错误关联、空值、重复值和表结构变化。

另外准备了：

- 200 道 CRM 搜索题；
- 120 道跨行业搜索题；
- 60 道从未用于调提示词的 QueryPlan 题；
- 6 道“诱导系统越权”的题；
- 45 道动作安全题。

这些数据都能用固定种子重新生成，不是手工改结果。

## 系统现在能完成什么

一个用户可以在网页中：

1. 登记本地表格；
2. 让系统发现表、字段、主键和表间关系；
3. 生成一批可审核的知识网络提案；
4. 人工接受或拒绝每一条提案；
5. 发布网络并进行增量构建；
6. 用自然语言提问，并查看回答所依据的表格行和关系；
7. 先模拟动作风险，再提交动作；
8. 高风险动作停在“等待确认”，不会偷偷执行；
9. 在评测页查看真实跑出来的数字。

我在真实浏览器里亲自按这条链路操作了一遍，不只是用代码假装点击。

## AI 理解问题的表现

DeepSeek 负责把自然语言变成 QueryPlan。新的 60 道题中，完整计划答对 93.33%，各个组件合计答对 97.52%。

它能做的事情不只是“扩展关键词”，还包括：识别要查哪类业务对象、提取筛选条件、安排跨表关系、决定是否聚合、发现问题缺少时间范围或判断标准，并在信息不足时要求追问。

安全上，普通查询计划不能直接执行打款、审批等动作，必须转到动作安全入口。

## 搜索效果到底怎么样

真实 BGE-M3 明显好于原来的哈希向量：第一名命中率从 3.5% 提高到 51.5%。但在这套包含大量订单号和客户号的数据里，BM25 的第一名命中率已经有 70%，最终混合检索只是追平 BM25。

这说明 Embedding 的引入是有效的，但不能为了简历好看就声称“混合检索一定更强”。未来需要增加更多不直接出现编号、依赖语义理解的问题，才能更公平地展示向量检索优势。

## 回答会不会胡说

我抽取 30 道不同类型的问题，让系统真实回答，再让 DeepSeek 按 Ragas 方法逐条检查回答是否能从证据中推出。

- 30 道全部成功评分；
- 平均 Faithfulness 为 0.9261；
- 最低一题为 0.8148。

这说明当前答案大部分忠于证据，但不代表每个答案都完全正确，也不代表已经评了全部 200 道 Faithfulness。

## 速度做了什么改进

第一次压 50 个同时请求时，混合检索最慢的一批要等约 49 秒。原因是程序把向量计算放在主通道里，大家只能排队。

修复后：

- 50 个请求全部成功；
- P95 从约 49 秒降到约 4.31 秒；
- 每秒处理能力从约 1 次提高到约 11.5 次。

这是一次由测试发现、代码修复、同条件复测证明的真实优化。

## 安全方面测了什么

- 没有 API Key 或 Key 错误时拒绝访问；
- 超长问题被拒绝；
- 外部 Embedding 限流、超时、服务错误时不会把坏向量写入系统；
- NaN、维度错误、数量错误都能识别；
- 动作支持允许、人工确认和拒绝三类结果；
- QueryPlan 不能绕过动作门禁；
- 真实密钥没有出现在仓库文件里。

## 目前最重要的不足

1. LightRAG 还没有真正接入，所以目前只能处理结构化表格，文档分支只是预留插口。
2. 系统还没有“某个员工只能看某些字段”的细粒度权限。薪资等敏感字段需要 RBAC 和字段分级。
3. 当前 Context Precision 是 0.14，不是简历草稿里的 0.78。
4. 本报告当时的 Top-5 检索算法对比只降低约 4.28%；后续新增传统 RAG 与 QueryPlan 的同口径对照，在 30 道多跳/聚合题上输入 Token 减少 66.78%。两个数字回答的问题不同。
5. 不配置 DeepSeek 时会使用较简单的规则理解器，复杂中文问题效果会下降。

## 现在是否适合演示

适合做秋招项目演示，而且可以演示一条完整、可信的链路。建议演示时使用 CRM 或供应链小数据，配置 DeepSeek 与 BGE-M3，重点展示：

> AI 建模提案需要人工审核；QueryPlan 把问题变成可检查的计划；回答带证据；高风险动作必须确认；评测数字来自冻结测试集。

不要在面试中使用尚未被实验支持的 0.78 和 36% 数字。使用本轮已验证的 93.33%、0.9261、48 个百分点提升和 91.2% 并发 P95 降幅更可信。
