## 本模块完成内容

- 后端测试从 50 项扩展到 59 项，加入三行业端到端链路、数据质量、精确编号检索、BM25 不调用向量服务、动作路由隔离和索引缓存测试；
- 采购、财务、人事共 4,440 个对象、4,600 条关系完成真实 SQLite 导入、构建、检索、风险模拟和无变更增量重跑；
- 加入 pytest-cov，可生成机器可读覆盖率结果；
- 全量后端测试 59 项通过，源码行覆盖率 89%；前端原有 2 项通过，TypeScript 检查和生产构建通过；
- Ruff 与 Mypy 严格检查通过。

## 测试发现并修复的问题

1. CSV 会把本表主键和恰好唯一的外键误拼成复合主键；已改为只声明最符合本表身份的初始主键。
2. `_code` 字段组合无法获得足够标识信号；已支持公司代码、部门代码类组合键。
3. BM25 模式仍会调用付费 Embedding；已完全分离。
4. 中文高频业务词会挤掉问题中的精确业务编号；已为带数字的结构化业务编号增加 BM25 查询权重，并加入回归测试。
5. QueryPlan 动作可带空实例，查询执行接口也未明确隔离动作；现要求单一明确实例，并强制动作只能走风险控制动作接口。
6. 远程 Embedding 每个批次重新建立 HTTP 客户端；现复用同一连接池。
7. 搜索每次从 SQLite 重读全部索引；已增加按索引版本管理的进程内文档缓存，并保持版本变化失效。
